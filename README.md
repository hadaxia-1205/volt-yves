# VOLT CORE

Vitrine de démonstration. Aucun paiement, aucun stock réel, aucune commande envoyée.

## Lancer

```bash
npm run dev
```

Le serveur écoute sur `0.0.0.0:3000`.

Le catalogue se modifie dans `src/data/products.ts`. Les visuels sont dans `public/images/produits/`.

## Vérifier

```bash
npm run lint
npm run typecheck
npm run build
```
